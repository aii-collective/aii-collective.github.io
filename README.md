# aii-collective.github.io

The organisation site for AI+I Collective, served by GitHub Pages from `main`.

## Layout

| Path | What it is |
|---|---|
| `index.html` | Language choice: 中文 / English |
| `briefing/deck-web.html` | Briefing deck for Beijing Academy of AI (11 slides) |
| `briefing/en.html` | English edition placeholder |
| `briefing/assets/` | Images and Portal recordings used by the deck |

## Publish

Push to `main`; GitHub Pages serves the repository root. No build step.

## Notes

The internal deck (`deck-zh.html` with the four Trios demo recordings) and the
demo videos are **not** in this repository.
